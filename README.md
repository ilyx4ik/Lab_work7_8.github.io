# Лабораторна робота 7–8 — Компонування

Адаптивна галерея кондитерських виробів на HTML та CSS. Сторінка використовує CSS Grid, Flexbox і медіа-запити. Фільтрація за категоріями реалізована CSS-радіокнопками без JavaScript.

## Файли

- `index.html` — розмітка сторінки.
- `style.css` — стилі, сітки та адаптивні медіа-запити.
- `assets/` — зображення десертів.
