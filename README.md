# Лабораторна робота 7–8 — Компонування

Адаптивна галерея кондитерських виробів на HTML та CSS. Сторінка використовує CSS Grid, Flexbox і медіа-запити. Фільтрація за категоріями реалізована CSS-радіокнопками без JavaScript.

## Файли

- `index.html` — розмітка сторінки.
- `style.css` — стилі, сітки та адаптивні медіа-запити.
- `assets/` — зображення десертів.

## Запуск локально

Розпакуйте архів і відкрийте `index.html` у браузері. Для перевірки адаптивності змінюйте ширину вікна браузера або використайте режим пристроїв у DevTools.

## Публікація на GitHub Pages

1. Створіть на GitHub публічний репозиторій, наприклад `lb7-8-Hnoiovyi`.
2. Завантажте до кореня репозиторію `index.html`, `style.css` та папку `assets`.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`, після чого натисніть **Save**.
5. Після публікації GitHub покаже адресу сторінки. Додайте її та адресу репозиторію до звіту.

> Для роботи сторінки всі файли мають зберігатися разом із папкою `assets`.
